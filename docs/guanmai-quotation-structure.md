## 3. 新建商品页

**URL**: `#/merchandise/manage/sale/sku_detail?salemenuId=S82092&salemenuType=4`

**面包屑**: 商品 > 商品管理 > 报价单管理 > 新建商品

页面结构与详情页一致，但所有字段为空值。部分字段在未选择分类前为禁用状态。

### 禁用字段（需先选择分类）

- 商品别名
- 自定义编码
- 基本单位
- 描述
- 税收分类编码
- 税收税率
- 检测报告

### 操作按钮

| 按钮 | 说明 |
|------|------|
| 取消 | 返回列表 |
| 保存 | 保存新商品 |
| 保存并新建 | 保存后继续新建 |
